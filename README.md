# AI-Assisted Multi-Platform Social Media Content Management and Automation System

Graduation project for managing, scheduling, publishing, and analyzing social media content across multiple platforms.

## Supported Platforms

- YouTube
- TikTok
- Instagram

## Planned Technology Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- ASP.NET Core
- C#
- Entity Framework Core
- PostgreSQL

### Background Processing
- Hangfire

### AI & Media
- OpenAI API
- FFmpeg
- ffprobe

### Infrastructure
- Docker
- GitHub Actions

## Development Strategy

The project follows a frontend-first development approach.

The frontend will initially be developed using mock data and later integrated with the ASP.NET Core backend.
